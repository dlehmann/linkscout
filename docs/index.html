Find every broken link
on your website.

Enter the address of a website – LinkScout crawls all its pages and checks every internal page, external link, image, PDF and download. It can also save complete websites for offline use.

Download Source on GitHub

Free and open source (MIT) · Linux and macOS (Apple Silicon) · runs locally, no account, no cloud

Everything you need to know about your links

LinkScout behaves like a browser: it sends the same headers as Firefox, keeps cookies and follows the browser's referrer rules, so servers answer it the way they answer your visitors.

One input

Only the start URL is needed. LinkScout finds all internal pages by itself and checks each URL exactly once.

All kinds of links

Internal pages, links to other websites (including where redirects end up) and files: images, PDFs, CSS, JavaScript, fonts, videos.

Overview with charts

Status of all URLs, response times, clicks from the start page, status codes and size by MIME type. Click any figure to see the matching URLs.

Sortable, filterable list

URL, status, MIME type, title, kind, clicks, size and time – filter by every value, open details with redirect chain and the pages that link to a URL.

Re-check and export

Export the results as JSON, import them later and re-check only the URLs that failed – or everything.

Password protected sites

HTTP Basic authentication is supported. Credentials are only sent to the checked site and never stored in reports.

Save websites offline

LinkScout downloads all pages of a website with their images, stylesheets, scripts, fonts and documents and rewrites the links, so the copy can be browsed from disk – or downloaded as ZIP.

  • Download list: add several websites, each with its own settings, and download them at the same time.
  • Flexible target folders: placeholders like <host> and <date>, default ~/Downloads/linkscout/<host>.
  • Project sites: a site in a sub-directory (like user.github.io/project) ends up directly in the target folder.
  • External resources: images, CSS and scripts from CDNs are included.

Install

LinkScout is a single, statically linked binary without dependencies. Start it without arguments and it opens its interface in your browser. The interface is available in English and German and follows your system language.

Linux (x86_64)

curl -LO https://github.com/dlehmann/linkscout/releases/latest/download/linkscout-linux-amd64.tar.gz
tar -xzf linkscout-linux-amd64.tar.gz
sudo install -m755 linkscout-*/linkscout /usr/local/bin/

For ARM boards (Raspberry Pi 4/5 and others) use linkscout-linux-arm64.tar.gz.

macOS (Apple Silicon)

curl -LO https://github.com/dlehmann/linkscout/releases/latest/download/linkscout-darwin-arm64.tar.gz
tar -xzf linkscout-darwin-arm64.tar.gz
xattr -d com.apple.quarantine linkscout-*/linkscout   # the binary is not signed
sudo install -m755 linkscout-*/linkscout /usr/local/bin/

From source (Arch, Debian, Ubuntu …)

sudo pacman -S go git            # Arch Linux
sudo apt install golang-go git   # Debian 13 or newer (needs Go ≥ 1.24)

git clone https://github.com/dlehmann/linkscout.git
cd linkscout
make install PREFIX=$HOME/.local   # binary, desktop launcher and icon

Without the browser

linkscout -report report.json https://example.com     # check, write a JSON report
linkscout -recheck report.json                         # re-check the failed URLs
linkscout -mirror ./example-offline https://example.com # offline copy
