Find every broken link
on your website.

Enter the address of a website – LinkScout crawls all its pages, checks every internal page, external link, image, PDF and download, and runs 48 SEO checks. It shows which external services the pages load, searches their content and can save complete websites for offline use.

Download Source on GitHub

Free and open source (MIT) · Linux and macOS (Apple Silicon) · runs locally, no account, no cloud

Everything you need to know about your website

LinkScout behaves like a browser: it sends the same headers as Firefox, keeps cookies and follows the browser's referrer rules, so servers answer it the way they answer your visitors.

One input

Only the start URL is needed. LinkScout finds all internal pages by itself and checks each URL exactly once.

All kinds of links

Internal pages, links to other websites (including where redirects end up) and files: images, PDFs, CSS, JavaScript, fonts, videos.

Overview with charts

Status of all URLs, response times, clicks from the start page, status codes, size by MIME type and external services. Click any figure to see the matching URLs.

External services

Which hosts your pages load fonts, statistics, videos, maps or scripts from – Google Fonts, Tag Manager, YouTube … – and on how many pages. Handy for the privacy policy.

Content search

Search the text or the HTML source of all pages as you type: an old phone number, the former company name, a forgotten tracking code. Regular expressions included.

Sortable, filterable list

URL, status, MIME type, title, kind, clicks, size, time and SEO issues – filter by every value, open details with redirect chain, SEO data and the pages that link to a URL.

Sitemap and robots.txt

The URLs of your sitemap are checked too – pages that are listed there but linked nowhere show up as orphans. URLs blocked by robots.txt are marked.

Compare runs

Compare the results with an earlier report: new and removed URLs, changed status codes, new and fixed SEO issues.

Export and re-check

HTML and PDF reports with every chart of the overview and the details of each URL; JSON and CSV exports with all data – of the whole site or just the filtered list. Import a report later, search it and re-check only the URLs that failed – or everything.

Password protected sites

HTTP Basic authentication is supported. Credentials are only sent to the checked site and never stored in reports.

Search, filter, export

The results list holds every URL with its status, title, MIME type, kind, clicks, date, size, time and SEO issues. Filter by any of them, sort, and open the details of a URL with its redirect chain, the pages that link to it and the external services it loads.

  • Content search: the visible text or the HTML source of all pages, as you type – plain text or regular expression. Every page shows its matches in context.
  • External services: filter the pages that load fonts, statistics, videos or maps from a certain host.
  • Export the list: exactly what the list shows, in its order – as CSV, JSON, a detailed PDF or a one-line-per-URL summary.
  • Search later: JSON reports keep the page content, so an imported report can be searched again.

48 SEO checks

Every internal page is analysed while it is checked – no extra requests, no account, nothing leaves your machine. The overview shows the SEO health of all pages and the length of titles and descriptions; the results list shows and filters the issues per URL, and the details explain each one with what exactly was found.

  • Indexability: noindex, missing or broken canonicals, robots.txt, sitemap entries with errors or noindex, orphan pages.
  • Content: missing, duplicate, too long or too short titles and meta descriptions, H1 and heading structure, duplicate content.
  • Links: redirect chains and loops, internal links to redirects, broken #anchors, mixed content, deep and rarely linked pages.
  • Markup: images without alt text or too large, hreflang, JSON-LD, viewport, lang, social media previews.
  • Site: security headers, certificate expiry, URL hygiene.

Site structure and sitemap.xml

The Sitemap tab shows every internal page as a tree by its URL path – with title, last modification date and the number of pages below each folder. A click on a page shows its details.

  • sitemap.xml for Google: ready for the Search Console, with lastmod from the server's Last-Modified header.
  • Only what belongs there: pages with noindex, another canonical URL or blocked by robots.txt are marked and left out.
  • As HTML: the tree as nested list, e.g. as a starting point for a sitemap page.

Save websites offline

LinkScout downloads all pages of a website with their images, stylesheets, scripts, fonts and documents and rewrites the links, so the copy can be browsed from disk – or downloaded as ZIP.

  • Download list: add several websites, each with its own settings, and download them at the same time.
  • Flexible target folders: placeholders like <host> and <date>, default ~/Downloads/linkscout/<host>.
  • Project sites: a site in a sub-directory (like user.github.io/project) ends up directly in the target folder.
  • Error pages included: pages answering 404 or 500 are saved anyway when they have content; the download list marks them and lists every URL with an error.
  • Update instead of starting over: a second run only downloads what changed and removes what is gone; a stopped download continues where it ended.
  • You decide what goes in: files on other websites, the pages of the sitemap, robots.txt and rules like -/private/* or -*.zip; requests per second and bandwidth can be limited.
  • External resources: images, CSS and scripts from CDNs are included.

Install

LinkScout is a single, statically linked binary without dependencies. Start it without arguments and it opens its interface in your browser. The interface is available in English and German and follows your system language.

Debian, Ubuntu (x86_64)

curl -LO https://github.com/dlehmann/linkscout/releases/latest/download/linkscout-amd64.deb
sudo apt install ./linkscout-amd64.deb

The package installs the program, a launcher in the application menu and the icon. For ARM boards (Raspberry Pi 4/5 and others) use linkscout-arm64.deb.

Arch Linux (x86_64)

curl -LO https://github.com/dlehmann/linkscout/releases/latest/download/linkscout-x86_64.pkg.tar.zst
sudo pacman -U linkscout-x86_64.pkg.tar.zst

For ARM (Arch Linux ARM) use linkscout-aarch64.pkg.tar.zst.

Other Linux distributions

curl -LO https://github.com/dlehmann/linkscout/releases/latest/download/linkscout-linux-amd64.tar.gz
tar -xzf linkscout-linux-amd64.tar.gz
sudo install -m755 linkscout-*/linkscout /usr/local/bin/

For ARM use linkscout-linux-arm64.tar.gz.

macOS (Apple Silicon)

curl -LO https://github.com/dlehmann/linkscout/releases/latest/download/linkscout-darwin-arm64.tar.gz
tar -xzf linkscout-darwin-arm64.tar.gz
xattr -d com.apple.quarantine linkscout-*/linkscout   # the binary is not signed
sudo install -m755 linkscout-*/linkscout /usr/local/bin/

From source

sudo pacman -S go git            # Arch Linux
sudo apt install golang-go git   # Debian 13 or newer (needs Go ≥ 1.24)

git clone https://github.com/dlehmann/linkscout.git
cd linkscout
make install PREFIX=$HOME/.local   # binary, desktop launcher and icon

Without the browser

linkscout -report report.json https://example.com      # check, write a JSON report
linkscout -report report.html https://example.com      # … or a readable report (.html, .pdf, .csv)
linkscout -recheck report.json                          # re-check the failed URLs
linkscout -report new.json -compare report.json https://example.com  # what changed?
linkscout -search "old-company.example" https://example.com    # pages that still mention it
linkscout -mirror ./example-offline https://example.com # offline copy
